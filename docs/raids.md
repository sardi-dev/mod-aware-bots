# Raid strategies

Each raid strategy activates only on its raid map (`PlayerbotAI::ApplyInstanceStrategies`, `src/AI/PlayerbotAI.cpp`)
and lives in `src/strategy/raids/<Raid>/`, registered in `RaidStrategyContext.h` and `RaidContexts.cpp`. Most are
ported from AzerothCore's mod-playerbots (`Ai/Raid/<Raid>`), adapted to the SkyFire 5.4.8 core and its client data.
Every spell id was checked in the 5.4.8 Spell.dbc, and every creature and object entry in the world database.

Role and index helpers the newer raid code expects from `PlayerbotAI` (assist tank, healer and ranged indexes, the bot
main tank) are in `src/strategy/raids/RaidRoles.h`.

Each raid strategy lives in `src/strategy/raids/<Raid>/` and activates only in its raid map: `PlayerbotAI::ApplyInstanceStrategies`
(`src/AI/PlayerbotAI.cpp`) adds the strategy named for the map, and `RaidStrategyContext.h` / `RaidContexts.cpp` register
it. Strategies ported from mod-playerbots keep its names, so `co +<name>` style toggles work the same way.

Shared pieces:

- `RaidBotHelpers.{h,cpp}`: the PlayerbotAI calls the ported strategies need that this module lacks (role indexes with a
  living-only option, item use on a unit or object, raid icon indexes) and spawn lookups by table guid (SkyFire gives
  instance spawns generated GUIDs, so a spawn is found near its spawn point once per instance and then by GUID). Also:
  a stagger timer for a short human reaction inside an action (`StaggerClock.h`, no delayed callbacks that could
  outlive the action), the charm cast path of a possessed creature's bar (the pet cast handler's checks), a heading
  sampler that tells where a seen unit moves from its position between looks, and a per-instance state store that
  resets in place and prunes instances nobody reads for 30 minutes.

Bot rule for every raid (owner, design decision 0016): bots play like players. No teleports, kills, damage, aura or resource
cheats, no movement-flag or flight hacks, no turning or steering bosses by code, no triggered casts that skip the
normal checks, and no reading of server state a player cannot see (movement destinations, private instance data). The
"Removed cheats" columns list what the 2026-11-16 audit took out after the ports.
- `RaidInterrupts.{h,cpp}`: mod-playerbots drops a cast from spell, creature and dynamic object script hooks that
  SkyFire lacks; PlayerbotAI polls each raid's `ShouldInterruptCast` while a bot is casting (casts with a cast time
  only, not channels).
